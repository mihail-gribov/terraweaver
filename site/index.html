A personal memory for any agent

Your life, remembered in your own words.

You mention a birthday, an allergy, a repair, in passing, between work questions. A month later your agent has forgotten, or kept it in words that are not yours. TerraWeaver listens by itself, keeps what is yours on your machine, and gives the agent facts, never decisions.

The hosted demo is for evaluation only: one shared memory, do not enter personal data. For real use, run it on your own machine.

Why another memory

What agent memory gets wrong today.

Memory for agents is now a layer of its own, and the same problems stay open in most of it. Each is a kind of question a long personal history asks, and a place where TerraWeaver was built to be different.

Counting: all of them"How many pieces of jewellery did I get in the last two months?" Similarity search returns the dozen entries most alike to the question, not every event. Here: each event is kept with its day and read into a graph; the answer gets every fact of the matter.
Time and the latest value"What happened two weeks ago?" "Which TV did we take in the end?" Here: new lies over old, each layer dated; the old choice stays, marked as overridden.
Where we left offNobody asks the memory, yet the new message goes on with an old matter. Here: the matter is put beside it, so a soundbar question comes with the TV that is on the wall.
It waits to be toldThe agent has to remember to write and to read, and mostly doesn't. Here: hooks hear every message of both sides; the agent passes nothing.
Facts in the agent's words"Up to 400", "she": a fact with no idea what or who. Here: each message is rewritten to stand alone from the agent's message just before it, and kept in your words in a plain Markdown journal you can read.
Decisions made for youMemory that picks and hides on its own authority. Here: facts and the words they stand on, never decisions; secrets are withheld before any model sees them.

Personal means yours

It is about you, so it stays with you.

A memory of a life is the most private thing an agent can hold. It is built to be read, checked and owned by the person it is about.

M

Your words

The journal is plain Markdown you can open and read. What the memory keeps is what you said, rewritten only so that it stands alone, with your original beside it.

⌂

On your machine

Run it yourself and the journal never leaves your machine. Only the model calls go out (reading, rewriting, deciding), and secrets are withheld before any of them.

✕

Secrets withheld

Passwords and keys are held back before any model sees them. A web query never carries a person's name or a private detail.

✓

Nothing decided for you

It gives the agent facts and the words they stand on. Choosing stays with you and your agent. It can take an entry out once you confirm which.

Active, not a store

It does the remembering, so you don't have to dictate.

A passive memory depends on the agent remembering to write and to read. This one acts by itself.

1

Hears

Claude Code hooks pass every message, yours and the agent's. The agent passes nothing.

2

Keeps

Only what is personal. "Up to 400" becomes "my budget for the vacuum is up to 400".

3

Reads in the quiet

Entries become people, things, values and links, each with the day it happened.

4

Hands over facts

When the agent asks, or a new message goes on with an old matter, it finds the entries by words, meaning and the graph, and hands over their texts.

What it answers

Long histories, exact answers.

Where a whole life no longer fits in a prompt, and the answer needs every fact that bears on it.

How it stands now"Which TV did we take in the end?" New lies over old, each layer dated.

Connect

Two ways in. Only one is for your life.

The memory is an MCP server: any agent can use say and ask. With the Claude Code plugin the hooks call say by themselves.

Your own memory

Runs on your machine. This is the real thing.

  1. Needs Python 3.12+, Claude Code, and keys for Nebius Token Factory and Tavily.
  2. Clone, install and start the memory: 
    git clone https://github.com/mihail-gribov/terraweaver
cd terraweaver
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m memory.server
  3. In another terminal, Claude Code with the plugin: 
    adapters/claude_code/claude-personal
  4. Talk about your life in passing. What it keeps is in var/memory/main/facts.md.

The hosted demo

For evaluation. Not a place for your life.

  1. Sign in with Google for a key (tw_…, shown once), or use a token you were given.
  2. Point your agent at it: 
    export PERSONAL_MEMORY_URL=https://terraweaver.life
export PERSONAL_MEMORY_TOKEN=tw_...
adapters/claude_code/claude-personal
    Any other MCP client: https://terraweaver.life/mcp, header Authorization: Bearer tw_....

One shared memory, for evaluation only. Do not enter personal data: everything typed goes into a shared journal that anyone with a key can see, and it may be erased. Use an invented person.

Under the hood

NVIDIA Nemotron on Nebius Token Factory.

Each model sits where it pays. Closed questions are answered from the first token's logprobs: one token, a probability instead of a guess.

RoleModel
Rewrite, read, decideNemotron 3 Super 120B-A12B
Judge: hundreds of small closed questionsNemotron 3 Nano 30B-A3B
Search by meaning: embeddings (on the demo, through OpenRouter)NVIDIA Nemotron embed 1B
